# Error de contrato: `--no-n1 --force` no puede bajar una cobertura cuando hay proveedor

La regla está escrita y es la correcta: **subir cobertura es automático, bajarla se declara.** `--force` existe para eso — *"sólo con `--no-n1`, y sólo donde éste baja una cobertura que ya estaba"*.

No se puede ejercer. `resolve_n1` vuelve antes de mirar los flags:

```rust
if let Some(f) = folded {
    return Ok(Some(N::of_level_1(f.clone())));
}
```

Si el fold salió, se escribe. `no_n1` y `force` se consultan **después**, en la tabla de siete filas, a la que sólo se llega cuando el fold falló — o sea cuando no hay proveedor. Así que las dos filas que `--force` gobierna son inalcanzables justo en la condición que las define: **bajar una cobertura sólo tiene sentido si se la podía adquirir.**

## Medido

**El 2026-09-02**, con lspd en `READY`:

```
$ bilinker accept --no-n1 --force 9662a432.1
  9662a432.1  981fe03c3692  803e56e62738  agree: Anibal
        ya estabas en el set y los valores no se movieron — nada que agregar
```

El `n` adquirido quedó intacto, sin aviso y sin error: **los dos flags se ignoraron en silencio**, que es peor que negarse. La renuncia se pudo escribir sólo apagando el daemon —`lspd stop`, y ahí el fold falla y la tabla decide—, o sea usando la falla de infraestructura que la regla existe para no confundir con una decisión.

## Por qué apareció ahora

Porque hizo falta. [`3z`](3z.task.md) es un vecindario que se resuelve al propio fragmento: **es un valor peor que la renuncia**, porque dice cubrir y no cubre. Renunciar ahí no es bajar la cobertura, es dejar de afirmar algo falso — y no había forma de hacerlo con el proveedor prendido.

Que la única salida fuera apagar el daemon es la señal: la herramienta obligó a producir la condición *"no pude mirar"* para poder decir *"no quiero mirar"*, que son exactamente las dos cosas que [`2r`](2r.task.md) separó.

## Qué toca

[`concepts/accept.md`](../../subsystems/bilinker/concepts/accept.md) § "Cuándo se adquiere el vecindario" — la tabla de siete combinaciones tiene que gobernar también el caso en que el fold salió, y hoy ese caso está antes de la tabla. El inventario de código sale de los no-OK.
