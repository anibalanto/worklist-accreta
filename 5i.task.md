# Error de reescritura: renombrar se come el salto de línea y el frontmatter deja de ser frontmatter

La descripción de `ACC-22` en Jira empieza así:

```
title: El terreno está preparado para trabajar spec-first status: done
created_at: 2026-08-29T00:00:00Z updated_at: 2026-08-30T00:37:31Z parent: ACC-14---
El terreno está preparado para trabajar spec-first
```

**El frontmatter viajó al proveedor como cuerpo.** Y no es la conversión: es el renombre, un paso antes.

## La causa, exacta

El regex que reescribe `parent:` **captura el delimitador y no lo restituye**:

```rust
r"parent:\s*{old_slug}(?:[^A-Za-z0-9_-]|$)"   // el grupo se come el \n
    .replace(&fm, format!("parent: {new_id}"))  // y no lo devuelve
```

Reproducido en un test de una línea:

```
antes:  "---\ntitle: X\nparent: 1\n---\n\n# X\n"
después: "---\ntitle: X\nparent: ACC-14---\n\n# X\n"
```

El `\n` desapareció, así que el cierre quedó `ACC-14---` y `split_frontmatter` **ya no encuentra `\n---\n`**. Devuelve `("", texto entero)`, y de ahí en adelante todo el archivo es cuerpo: se convierte a ADF —donde el `---` inicial pasa a ser un `rule` y las líneas del frontmatter se pegan en un párrafo— y vuelve así.

## Por qué se vio recién ahora

**Porque `parent` es la última línea del frontmatter.** Si estuviera en el medio, comerse el `\n` sólo pegaría dos líneas de YAML: el frontmatter seguiría abriendo y cerrando, el bloque se seguiría separando, y el daño sería una línea fea adentro de un campo que igual se reescribe. Siendo la última, rompe el cierre y arrastra el archivo entero.

Y `1.epic.md` no tiene `parent`, así que su descripción salió bien. El defecto aparece **sólo en los ítems que cuelgan de algo** — que son casi todos.

Los tests de renombre son once y **ninguno mira `parent`**: cubren destinos de link, ids entre backticks y `relation.<tipo>`, que son las otras tres posiciones.

## Cuándo está hecha

- El renombre conserva el salto de línea, y hay un test con `parent` como **última** línea del frontmatter.
- Un test verifica que `split_frontmatter` siga separando después de renombrar — que es la propiedad que se rompió, y que no se ve mirando sólo el `parent`.
- La descripción de las cuatro de `secure/sprint/1` en Jira arranca en su título y no en `title:`.
